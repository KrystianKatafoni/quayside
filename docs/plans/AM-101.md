# AM-101 · Gradle wrapper, katalog wersji, convention plugins w build-logic

Issue: #9 · Wymagania: ENG-M1, ENG-M2 · Etap: M1

## Zakres

Robimy:

- Gradle wrapper 9.7.1 (wspierany przez Kotlin 2.4.20+), JDK 21 przez toolchain.
- `gradle/libs.versions.toml`: Kotlin 2.4.21, Compose Multiplatform 1.12.2, kotlinx.coroutines 1.11.0, JUnit 6.1.3, Kotest 6.2.6.
- `build-logic` (included build) z czterema convention plugins:
  - `am.kotlin` — Kotlin/JVM, toolchain 21, ostrzeżenia jako błędy, JUnit Platform, zależności testowe (JUnit, Kotest assertions, coroutines-test).
  - `am.feature.api` — `am.kotlin` + `java-test-fixtures` + explicit API mode (każdy publiczny typ kontraktu ma jawną widoczność).
  - `am.feature.impl` — `am.kotlin` (reguła „impl nie zależy od impl/ui” to AM-104).
  - `am.feature.ui` — `am.kotlin` + kompilator Compose + plugin Compose Multiplatform + runtime/foundation.
- `settings.gradle.kts` i główny `build.gradle.kts`: repozytoria tylko w settings (`FAIL_ON_PROJECT_REPOS`), `./gradlew check` uruchamia też testy `build-logic`.
- Testy `build-logic` w Gradle TestKit.

Nie robimy (osobne zadania): moduły `core:*` (AM-102+), Konsist i reguła impl→impl (AM-104), Spotless/detekt/Kover/`quickCheck` (AM-105), aplikacja Compose (AM-108).

## Moduły

`build-logic`, pliki główne Gradle (`settings.gradle.kts`, `build.gradle.kts`, `gradle/`, `gradlew*`), `CLAUDE.md` (sekcja poleceń), `docs/ROADMAP.md`.

## Zmiany API

Brak (nie ma jeszcze modułów produkcyjnych). Publicznym „API” tego zadania są identyfikatory pluginów `am.kotlin`, `am.feature.api`, `am.feature.impl`, `am.feature.ui`.

## Testy

- [x] funkcjonalne `build-logic` (TestKit, `ConventionPluginsTest`):
  - `am.kotlin` kompiluje kod i uruchamia test JUnit z asercją Kotest,
  - `am.feature.api` odrzuca publiczną deklarację bez modyfikatora widoczności (explicit API) i kompiluje `testFixtures`,
  - `am.feature.impl` kompiluje moduł,
  - `am.feature.ui` kompiluje funkcję `@Composable`.
- jednostkowe, kontraktowe, funkcjonalne aplikacji: nie dotyczy.

## Ryzyka i pytania

- Sesja w chmurze nie ma dostępu do Maven Central i Gradle Plugin Portal, więc build weryfikuje CI na macOS w PR.
- Nowe wersje Kotlin/Gradle/Compose: zgodność Kotlin 2.4.2x ↔ Gradle 9.7 potwierdzona w informacji o wydaniu Kotlin 2.4.20; Dependabot będzie podbijał wersje.
- Toolchain bez automatycznego pobierania JDK: lokalnie wymagany JDK 21 (README, sekcja „Wymagania deweloperskie”).
