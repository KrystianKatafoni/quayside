# AM-104 · Testy architektury Konsist + reguła Gradle impl→impl

Issue: #12 · Wymagania: ENG-M3–M8, ENG-T5 · Etap: M1

## Zakres

Dwie warstwy wymuszania reguł z `docs/11-koncepcja-techniczna.md` §3:

1. **Gradle (`build-logic`)** — błąd już przy deklaracji zależności:
   - `am.feature.impl`: nigdy `:feature:*:impl` ani `:feature:*:ui`,
   - `am.feature.ui`: nigdy `:feature:*:impl`,
   - `am.feature.api` (także moduły `core`): tylko `:core:domain`, `:core:design-tokens`, `:core:testing`.
2. **Konsist (`tests:architecture`)** — reguły, których Gradle nie widzi:
   - `core:domain` i `feature:*:api` bez importów `java.io`, `java.net`, `ProcessBuilder`, `androidx.compose`,
   - pakiet zgodny ze ścieżką modułu (`dev.agentmanager.<feature>.<warstwa>`, `dev.agentmanager.core.<moduł>`),
   - w `impl` klasy, interfejsy i obiekty są `internal`/`private` (publiczna tylko fabryka modułu, funkcja),
   - klasy `*Adapter` tylko w `impl`,
   - `object` bez właściwości `var`.

Reguła dla modułów, których jeszcze nie ma (np. `impl`), jest raportowana jako **pominięta**, a nie zaliczona, żeby było widać, że jeszcze niczego nie sprawdza.

## Moduły

`build-logic` (reguły + testy), `tests:architecture` (nowy), `gradle/libs.versions.toml` (Konsist 0.18.1), `settings.gradle.kts`.

## Zmiany API

Brak zmian w modułach produkcyjnych.

## Testy

- [x] `build-logic`: `ModuleRulesTest` — klasyfikacja ścieżek oraz TestKit: impl→impl i api→api przerywają build, dozwolone zależności przechodzą (4)
- [x] `tests:architecture`: `ModuleBoundariesTest` (6; 3 pominięte, bo nie ma jeszcze `impl`, adapterów ani `feature:*:api`)
- [x] sprawdzenie mutacyjne (ręcznie): plik w `core:domain` z `import java.io.File`, złym pakietem i `object` z `var` → 3 testy czerwone

## Ryzyka i pytania

- Reguła `api` obejmuje moduły `core` (używają tego samego pluginu). Gdy `core:process` lub `core:storage` będą potrzebować innej zależności, dostaną własny plugin `am.core`.
- Konsist parsuje źródła własnym kompilatorem; nowa składnia Kotlina może wymagać aktualizacji Konsist.
