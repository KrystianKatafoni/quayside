# AM-311 · Spike: stare sesje projektu z dysku

Issue: #169 · Wymagania: FR-P9 · ENG-C8, ENG-C10, ENG-T6, ENG-T7 · ADR 0002, 0029 · Zależy: AM-310 · Blokuje: AM-312, AM-313, AM-314

## Zakres

Spike odpowiada na pytanie, jak z plików `<claudeHome>/projects/<zakodowany cwd>/<uuid>.jsonl` zbudować listę starych sesji projektu bez czytania całych plików (do 159 MB) i jak taką sesję wznowić. Trzy części, jeden PR (ok. 250 linii `src/main` + test):

- **(a) Pomiar na Macu** (narzędzie w testach, uruchamiane ręcznie): agregaty z prawdziwego katalogu (bez żadnych fragmentów plików).
- **(b) Parser w `agent-runtime:impl`** (`internal`, w `src/main`, jeszcze niepodpięty): początek i koniec pliku → metadane sesji, kodowanie nazwy katalogu, kandydaci dla projektu. TDD na fixtures syntetycznych odtworzonych z agregatów (a).
- **(c) Wynik** w `docs/compat.md` (nowa sekcja i wiersze tabeli) oraz rekomendacje dla AM-312, AM-313, AM-314.

**Nie robimy:** zmian żadnego `api`, podpięcia w `sessions:impl` ani w `app`, UI, limitów wieku i liczby (AM-312), akcji „Wznów” (AM-313), ADR (decyzję o źródle i formacie podejmuje ADR z AM-312), poprawek `FileSessionMetaSource` z AM-818 (rozjazd kodowania → `/triage`, osobne zadanie), wpisu w CHANGELOG.

## Decyzje człowieka (2026-11-10)

Te decyzje mają pierwszeństwo przed resztą planu, jeśli się z nią różnią.

1. **Gdzie żyje parser: wariant (A).** Parser zostaje w `agent-runtime:impl`. AM-312 doda port w `agent-runtime:api` (np. `SessionHistory`) i dopisze ten moduł do swojej listy modułów, po osobnym pytaniu do człowieka o zmianę `api`. Rekomendacja ma trafić do `docs/compat.md`.
2. **Pomiar M9 wykonuje implementer lokalnie** na sesjach testowych w `~/quayside-am311/` (nigdy na prawdziwych rozmowach), z `claude stop` i `claude rm` na końcu. Model `haiku`, kilka tur.
3. **Fixtures plików sesji są tylko syntetyczne.** Żaden fragment prawdziwego pliku `.jsonl` nie trafia do repo. Dlatego odpada nagrywanie wycinków (`QUAYSIDE_AM311_RECORD`) i lista dozwolonych pól: fixtures odtwarzamy ręcznie na podstawie agregatów z raportu M1–M8. Raport pozostaje tylko z agregatami. Nagrania wyjścia CLI z M9 (sesje testowe) są dozwolone po anonimizacji wg README `fixtures/agents-json/`.

## Zmiany API

Feature `api`: **brak**. Typy `internal` w `agent-runtime:impl`. Reguły poniżej to wynik pomiaru M1–M4 (stan po implementacji); kod jest w repozytorium, tu tylko kształt:

```kotlin
/** Metadata of one Claude Code session file; [title] is user data (ENG-C8): never logged. */
internal data class SessionFileSummary(
    val sessionId: String,        // UUID = file name stem (conversation id, not the short supervisor id)
    val startCwd: Path,           // cwd of the first entry that has an absolute cwd (start directory)
    val startedAt: Instant?,      // first `timestamp` in the head
    val lastActivityAt: Instant?, // last `timestamp` in the tail
    val cwdChanged: Boolean,      // more than one distinct cwd seen in head + tail (lower bound: the middle is not read)
    val title: String?,           // first real user message, at most 80 code points; null when none in the head
)

/** Why a file is not a listable session; fixed categories, never file text. */
internal enum class SessionFileProblem { UNREADABLE, NOT_JSONL, NO_SESSION_ID, ID_MISMATCH, NO_CWD, SIDECHAIN }

internal object SessionFiles {
    /** Pure. [head] may end and [tail] may start in the middle of a line; such partial lines are skipped. */
    fun parse(fileStem: String, head: String, tail: String, headIsWhole: Boolean): Outcome<SessionFileSummary, SessionFileProblem>
    /** Pure: directory name Claude Code 2.1.322 uses for [cwd]: every non-[A-Za-z0-9] UTF-16 unit → "-"; over 200 chars: first 200 + "-" + base36(|hashCode|). */
    fun dirNameOf(cwd: Path): String
    /** Pure: [dirNames] that may hold sessions of [project] or its subfolders (equal or prefix + "-"; for a name over 200 chars the first 200); the cwd check follows. */
    fun candidates(project: Path, dirNames: List<String>): List<String>
}

/** Reads at most [headBytes] from the start and [tailBytes] from the end of [file] on [io]. Never throws except cancellation. */
internal class SessionFileReader(private val io: CoroutineDispatcher, private val headBytes: Int = 64 * 1024, private val tailBytes: Int = 64 * 1024) {
    suspend fun read(file: Path): Outcome<SessionFileSummary, SessionFileProblem>
}
```

Reguła projektu (potwierdzona M4: 15 plików po `cwd` = 15 po nazwie, 0 fałszywych kandydatów): plik należy do projektu P, gdy `startCwd` leży w `P.dir` (jak `isUnder`). Nazwa katalogu służy tylko do wstępnego odsiewu, bo kodowanie jest stratne (`/a/b-c` i `/a/b/c` dają to samo). Podfolder: `ProjectGroups.subfolderOf(startCwd)` w AM-312.

## Wynik pomiaru (2026-11-10, Claude Code 2.1.322)

Pełne wyniki M1–M9 i rekomendacje są w `docs/compat.md`, sekcja „Pliki sesji na dysku (pomiar AM-311)”. Reguły zapisane w kodzie:

- Pierwszy wpis prawdziwych plików nigdy nie ma `cwd` (0 z 132); pierwsze bezwzględne `cwd` jest na pozycji 3–9 i zawsze w głowie 64 KiB. `startCwd` = pierwsze bezwzględne `cwd`, `startedAt` = pierwszy `timestamp` w głowie, `lastActivityAt` = ostatni `timestamp` w ogonie (przy pliku w całości: w głowie).
- Kodowanie katalogu: znak UTF-16 spoza `A-Za-z0-9` → `-` (emoji daje `--`); powyżej 200 znaków: pierwsze 200 + `-` + `abs(hashCode)` ścieżki w systemie 36. `candidates` dla długiej nazwy projektu dopasowuje po pierwszych 200 znakach.
- Tytuł: pierwsza wiadomość `user` bez `isMeta` i bez prefiksu `<command-name>`, spłaszczona do jednej linii, do 80 code pointów. Odrzucane są też wiadomości zaczynające się od `<command-` (`<command-name>`, `<command-message>`) i `<local-command-`; w próbce 8 plików zaczynało od `<command-message>` i 2 od `<command-name>`. Prefiks `Caveat:` nie jest osobno odrzucany (w próbce zawsze towarzyszy `isMeta`).
- Wpisów `summary` w 2.1.322 nie ma; są `custom-title` (`customTitle`), `agent-name`, `last-prompt`.
- M9 (R1–R5, sam prompt bez flag i brak promptu dla sesji spoza supervisora): wyniki R1–R5 w `docs/compat.md`; nagrania w `fixtures/cli/recorded/2.1.322-bg-resume-*`. Hipoteza R3 („nie znaleziono rozmowy”) nie potwierdziła się: rozmowa jest znajdowana po UUID z dowolnego zaufanego katalogu.

## Ryzyka i pytania

**Pytanie blokujące (rozstrzygnięte 2026-11-10: wariant A, zob. „Decyzje człowieka”):**

1. **Gdzie żyje odczyt plików sesji w produkcji.** Roadmapa AM-311 mówi `agent-runtime:impl`, a docs/11 §10 każe trzymać wiedzę o formatach Claude Code w tym module. AM-312 umieszcza jednak „nowe źródło” w `sessions:impl`, gdzie już jest `TranscriptTail` (AM-818). Sesje z `sessions:impl` nie widzą `internal` z `agent-runtime:impl` (reguła `impl` → nie-`impl`). Dlatego parser z tego spike'a da się użyć tylko na dwa sposoby:
   - (A) AM-312 dodaje port w `agent-runtime:api` (np. `SessionHistory`), czego lista modułów AM-312 dziś nie ma;
   - (B) parser i fixtures idą od razu do `sessions:impl`, ale to wymaga zmiany modułów AM-311 w roadmapie.

   Propozycja domyślna: (A), zgodnie z docs/11. Do potwierdzenia przez człowieka razem z dopisaniem `agent-runtime:api` do AM-312.

**Pytania nieblokujące** (domyślna decyzja w nawiasie):

- Pytanie 2, kto wykonuje M9: rozstrzygnięte, implementer lokalnie na sesjach testowych (decyzja 2). Katalogi testowe wymagały zaufania nadanego interaktywnym `claude`.
- Pytanie 3, czy publiczne repo może mieć wycinki prawdziwych plików: rozstrzygnięte, nie (decyzja 3), tylko fixtures syntetyczne.

**Ryzyka:**

- **Dane użytkownika.** Pliki zawierają całe rozmowy, wyniki narzędzi i sekrety wklejone do promptów. Chronią przed tym: anonimizacja przez listę dozwolonych pól (nie przez listę zakazanych), raport tylko z agregatami, test anonimizacji i przegląd człowieka. `title` nigdy nie trafia do logów ani do `SessionFileProblem`.
- **Wznowienie dopisuje do transkryptu**, a R4 może dać dwóch piszących do jednego pliku. Dlatego M9 tylko na sesjach testowych. Gdy R4 okaże się groźne, AM-313 musi to blokować.
- **Kodowanie nazwy katalogu** może różnić się od AM-818 (znaki spoza ASCII, długie ścieżki). Wtedy AM-818 ma błąd poza zakresem (`/triage`); `candidates` i tak sprawdza `cwd` z pliku.
- **Głowa 64 KiB** może nie zawierać pierwszej wiadomości (duży `CLAUDE.md` lub załącznik na starcie). M7 pokaże, czy trzeba zwiększyć limit. `title=null` to stan dozwolony.
- **Kod w `src/main` bez podpięcia** czeka na AM-312. Gdy człowiek wybierze (B), AM-312 przenosi go do `sessions:impl`.
- **`CLAUDE_CONFIG_DIR`** (ADR 0029): katalog główny jest parametrem (`<claudeHome>/projects`), nigdy stałą `~/.claude`.

**Kolejność commitów:** 1) `FixtureAnonymity` i narzędzie pomiaru (test); 2) fixtures syntetyczne z README; 3) `SessionFiles`, `SessionEntries` i `SessionFileReader` z testami (TDD); 4) nagrania `--resume` i `docs/compat.md`; 5) korekta tego planu do faktycznych reguł.
