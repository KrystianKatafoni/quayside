# AM-406 · command-palette:api/impl: komendy, skróty, CommandRegistry, wyszukiwanie

Issue: #30 · Wymagania: FR-K1, FR-K2 (część) · ENG-I1–I8, ENG-C2, ENG-C8, ENG-C10, ENG-T2 · docs/05 „Skróty”, docs/11 §2–§4 · ADR 0011 (przyjęta) · Zależy: AM-405

## Zakres

Pierwszy z trzech etapów palety i skrótów (podział przyjęty przez człowieka 2026-10-19, ENG-C10). Ten PR dostarcza **kontrakt i rejestr bez UI**:

- typy komendy i skrótu w `command-palette:api` (`Command`, `CommandId`, `CommandGroup`, `Shortcut`, `KeyChord`, `ChordKey`, `KeyModifier`, `CommandProvider`, `CommandRegistry`);
- czystą regułę wyszukiwania `CommandMatcher` w `api`;
- rejestr w `command-palette:impl` i fabrykę `commandPaletteModule`;
- `FakeCommandRegistry`, `CommandRegistryContract` i builder komend w `testFixtures(api)`;
- docs/11: §2 (wyszukiwanie w `api`, w `impl` tylko rejestr) i §4 (`Command.shortcut: Shortcut?` zamiast Compose `KeyShortcut?`).

Nie robimy: modułu `command-palette:ui`, wpięcia w `app`, komend projektów i sesji (AM-408); obsługi klawiszy, `j`/`k`, `g p` (AM-409); `x` i akcji panelu (AM-410); `⏎` (AM-505); `r` i `space` (AM-411). Bez zmian `projects:*`, `sessions:*`, `mission-control:ui`, `app`.

## Zmiany API (`command-palette:api`)

```kotlin
/** Stable id of a command, e.g. `projects.add` or `projects.goto.<projectId>`; logged and tested, never shown. */
@JvmInline public value class CommandId(public val value: String) // init: require(value.isNotBlank())

/** Modifier of a [KeyChord]; independent of Compose (ENG-I8). */
public enum class KeyModifier { META, SHIFT, ALT, CTRL }

/** The key of a [KeyChord]: a lower-case letter or digit, or a named key. */
public sealed interface ChordKey {
    /** @throws IllegalArgumentException unless [char] is in `a..z` or `0..9`. */
    public data class Letter(val char: Char) : ChordKey
    public enum class Named : ChordKey { ENTER, ESCAPE, SPACE, BACKSPACE, UP, DOWN }
}

public data class KeyChord(val key: ChordKey, val modifiers: Set<KeyModifier> = emptySet())

/** One chord (`⌘K`) or a sequence of two (`g p`). @throws IllegalArgumentException for 0 or more than 2 chords. */
public data class Shortcut(val chords: List<KeyChord>) { public companion object { public fun of(vararg chords: KeyChord): Shortcut } }

/** Where a command is listed; the palette shows groups in this order. */
public enum class CommandGroup { PROJECT, GO_TO_PROJECT, SESSION, APP }

/**
 * One action of the palette (FR-K1). [run] is called on the palette's scope (Main dispatcher), must not block and
 * must not throw except CancellationException; it shows its own errors (e.g. as a dialog of its feature).
 * @property title localised text; may hold a project name, so it is never logged (ENG-C8).
 * @property keywords extra words the search matches, e.g. `rename`.
 */
public data class Command(
    val id: CommandId, val title: String, val group: CommandGroup,
    val keywords: List<String> = emptyList(), val shortcut: Shortcut? = null, val run: suspend () -> Unit,
)

/** A source of commands that change with the app state (e.g. one per project). */
public interface CommandProvider { public val commands: StateFlow<List<Command>> }

/**
 * Every command the app offers now. [register] and [AutoCloseable.close] may be called from any thread.
 * [commands] lists providers in registration order and keeps each provider's own order. A duplicate [CommandId]
 * keeps the first command. A duplicate [Shortcut] keeps the first binding, the later command stays without a shortcut.
 */
public interface CommandRegistry {
    /** Adds [provider] until the returned handle is closed; closing twice does nothing. */
    public fun register(provider: CommandProvider): AutoCloseable
    public val commands: StateFlow<List<Command>>
}

/** Pure search of the palette (decision 3); shared by `ui`, `impl` and fakes, like `ProjectInputRules`. */
public object CommandMatcher { public fun search(query: String, commands: List<Command>): List<Command> }
```

`command-palette:impl`: `public fun commandPaletteModule(scope: CoroutineScope, logger: Logger): CommandRegistry` (KDoc: `scope` żyje tyle co aplikacja, jak `sessionsScope` w `Main.kt`), a pod nim `internal class InMemoryCommandRegistry`.

### Decyzje (przyjęte 2026-10-19)

1. **Komendy składa `app`** (ADR 0011). Klasa `AppCommands` (AM-408) buduje listę z publicznych intencji kontrolerów `ui`. Moduły `ui` innych feature'ów nie zależą od `command-palette:api`. Ten PR tylko udostępnia rejestr.
2. **Własny typ skrótu** zamiast Compose `KeyShortcut` (ENG-I8, Konsist). Skróty z ⌘ obsłuży `MenuBar`, a skróty bez ⌘ `Window.onKeyEvent` w AM-409. Mapowanie `KeyEvent` → `KeyChord` będzie w `command-palette:ui`.
3. **`CommandMatcher.search`**: zapytanie po `trim`, bez wielkości liter i bez polskich znaków (`Normalizer` NFD, usunięte znaki diakrytyczne; „ł” → „l” osobno). Dopasowujemy tytuł i `keywords`, a o kolejności decyduje najlepszy poziom: prefiks tytułu > początek słowa > podciąg > podsekwencja liter. Remis rozstrzyga kolejność `CommandGroup`, a potem kolejność wejścia. Puste zapytanie zwraca wszystko w kolejności grup i wejścia. Reguła jest w `api`, bo `ui` nie widzi `impl`, a fake nie powinien powtarzać algorytmu.
4. **Rejestr**: lista providerów w `MutableStateFlow`, `commands` przez `flatMapLatest` + `combine` + `stateIn(scope, Eagerly, …)`. Duplikat id albo skrótu daje WARN z kategorią (`duplicateId`/`duplicateShortcut`) i `commandId`, bez tytułu.

## Ryzyka

- `Command` to `data class` z lambdą, więc równość list jest zawsze fałszywa i `stateIn` emituje przy każdej zmianie źródła. Lista jest krótka, a koszt pomijalny.
- `flatMapLatest` jest `@ExperimentalCoroutinesApi`; przy `allWarningsAsErrors` potrzebne `@OptIn` w jednym miejscu. Alternatywa bez opt-in: przeliczanie w kolektorze listy providerów.
- Normalizacja NFD nie usuwa „ł”, dlatego test `"lacz"` → „Łącz…” wymaga osobnej zamiany.
