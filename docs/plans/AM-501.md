# AM-501 · Spike: JediTerm w SwingPanel (fokus, skróty, HiDPI)

Issue: #31 · Wymagania: FR-T1 · ENG-I8, ENG-M4, ENG-T3, ENG-C10 · docs/06, docs/09 (ryzyko „JediTerm w Compose”, plan B: osobne okno Swing), docs/11 §3 (wyjątek `JComponent`) · ADR 0001 (przyjęta), szkic ADR 0012 · Zależy: AM-108

## Zakres

Sprawdzamy na Macu, czy JediTerm + pty4j osadzone przez `SwingPanel` w oknie Compose spełnia wymagania co do fokusu, skrótów, HiDPI i resize. Wynik: wypełniona tabela obserwacji (niżej) i ADR 0012 z decyzją **TAK / plan B / NIE**.

1. **`feature:terminal:impl`** (nowy moduł, `am.feature.impl`): zalążek produkcyjnego kodu, który AM-502 przejmie i schowa za `TerminalApi`. Zawiera `internal` adapter PTY (pty4j → `TtyConnector` JediTerm), ustawienia widżetu i jedną publiczną fabrykę spike'a.
2. **`app`**: osobny zbiór źródeł `terminalSpike` (nie trafia do `main` ani do `.dmg`) z oknem testowym i taskiem `./gradlew :app:runTerminalSpike`. Produkcyjne `Main.kt` i `MainWindow.kt` się nie zmieniają.
3. Kod spike'a **zostaje w repo**: moduł `terminal:impl` jest fundamentem AM-502. Okno `terminalSpike` usuwa AM-503, gdy `terminal:ui` przejmie osadzanie.

Okno testowe `TerminalSpikeMain.kt`: po lewej kolumna Compose (`TextField`, etykieta z ostatnim klawiszem, który zobaczył Compose `onKeyEvent`). Po prawej `SwingPanel` z `zsh -l` w katalogu domowym. Dalej: atrapa palety ⌘K (nakładka Compose z `TextField`, Esc zamyka i oddaje fokus terminalowi przez `requestFocusInWindow()`) oraz przełącznik „Przechwytuj skróty aplikacji”, który dodaje `KeyboardFocusManager.addKeyEventDispatcher` dla ⌘K (wariant B). Są też przyciski: „Ukryj/pokaż terminal” (test `removeNotify`), „Pełna szerokość” (resize/reparent) i „Otwórz w osobnym oknie” (plan B: `JFrame` z tym samym widżetem). Właściwość `-PspikeBlending=true` ustawia `compose.interop.blending=true` (paleta nad terminalem).

**Nie robimy:** `terminal:api`, `TerminalApi`/`TerminalSession`, profile powłoki, `attach`/`logs`, OSC 133 (AM-502); kart, paneli, maksymalizacji, `terminal:ui` (AM-503); szukania i ustawień terminala (AM-504); skrótu ⏎ attach (AM-505); reguły Konsist „JediTerm tylko w `terminal:impl`” (AM-502); podpisu natywnych bibliotek pty4j (AM-901/902); wpisu w CHANGELOG (nic widocznego dla użytkownika).

## Moduły

- `settings.gradle.kts`: `include(":feature:terminal:impl")` + repozytorium JetBrains (decyzja 1 w „Ryzykach”) jako `exclusiveContent` tylko dla grupy `org.jetbrains.jediterm`.
- `gradle/libs.versions.toml`: `jediterm = "3.76"`, `pty4j = "0.14.0"`; biblioteki `jediterm-core`, `jediterm-ui` (`org.jetbrains.jediterm`), `pty4j` (`org.jetbrains.pty4j:pty4j`). `jediterm-ui` deklaruje `jediterm-core` jako `runtime`, więc oba wpisujemy jawnie.
- `feature/terminal/impl/`: `build.gradle.kts`; `src/main/kotlin/dev/quayside/terminal/impl/`: `TerminalSpike.kt` (publiczna fabryka), `PtyTtyConnector.kt` (rozszerza `ProcessTtyConnector` z jediterm-core; `resize` → `PtyProcess.winSize`), `TerminalWidgetSettings.kt` (`DefaultSettingsProvider`: font, Option jako Meta, bez kopiowania przy zaznaczeniu); testy w `src/test/kotlin/…`.
- `app/build.gradle.kts`: zbiór źródeł `terminalSpike` (klasy `main` + jego zależności, `project(":feature:terminal:impl")`), task `runTerminalSpike` (`JavaExec`), `check` zależy od `compileTerminalSpikeKotlin` (żeby kod nie gnił). `app/src/terminalSpike/kotlin/dev/quayside/app/terminalspike/TerminalSpikeMain.kt` oraz `SpikeParts.kt` (elementy okna: kolumna sterowania, paleta, `KeyEventDispatcher`, osobne okno; wydzielone, bo detekt/ENG-C10 limituje rozmiar pliku i funkcji).
- `docs/adr/0012-jediterm-pty4j-w-swingpanel.md` (szkic gotowy; po spike'u Krystian wpisuje wyniki i zmienia status), ten plan, `docs/ROADMAP.md` (pole `moduły:` → `terminal:impl, app`).

## Zmiany API

Feature `api`: brak (`terminal:api` powstaje w AM-502). Publiczny element `terminal:impl` to wyłącznie fabryka (ENG-M4; Konsist zabrania publicznych klas w `impl`, więc tylko typy JDK, stdlib i `core:domain`):

```kotlin
/**
 * Spike AM-501, replaced by `terminalModule` in AM-502. Starts [command] in a PTY (pty4j, TERM=xterm-256color)
 * and returns the JediTerm widget with a handle that closes the widget and kills the process tree.
 * No JediTerm or pty4j type escapes (ENG-I8). Call on the AWT event thread (it builds a Swing component).
 * @return Err with [TerminalSpikeErrors] category: work dir missing or the PTY did not start (never the
 *   exception message, it may quote the environment).
 */
public fun openSpikeTerminal(command: ShellCommand, logger: Logger): Outcome<Pair<JComponent, AutoCloseable>, String>

/** Stable error categories of [openSpikeTerminal]. */
public val TerminalSpikeErrors: Set<String> = setOf("work-dir-missing", "pty-start-failed")
```

## Decyzje

1. Okno testowe w `app` (zbiór `terminalSpike`), nie w `terminal:impl`: `impl` zostaje bez Compose, a tylko `app` widzi `impl` (docs/11 §3). Alternatywa: zbiór `spike` w `terminal:impl` z pluginem Compose; odrzucona, bo dokłada Compose do `impl`.
2. Testy PTY w `src/test` modułu (repo nie ma zbioru `integrationTest`; tak samo testuje `core:process`), `@Timeout(10)`, tylko `/bin/sh`, bez sieci i Claude Code.
3. Wynik spike'a zapisujemy w ADR 0012 (sekcja „Wyniki”), bez osobnego raportu w `docs/`.

## Ryzyka i pytania

**Przyjęte decyzje (Krystian, 2026-10-19):**

1. **Repozytorium Maven.** JediTerm 3.76 nie ma w Maven Central. Dodajemy `https://packages.jetbrains.team/maven/p/ij/intellij-dependencies` w `dependencyResolutionManagement` jako `exclusiveContent { forRepository { maven(url) }; filter { includeGroup("org.jetbrains.jediterm") } }`. Nic poza tą grupą nie przychodzi z tego repozytorium. W chmurze host może być poza allowlistą sieci; wtedy build weryfikuje CI.
2. **Licencje.** JediTerm na Apache 2.0 (README: „LGPLv3 lub Apache 2.0”), pty4j na EPL-1.0, JNA na Apache 2.0. Teksty licencji trafiają do pakietu w AM-901.
3. **Zakres modułów.** Zgoda na `app` (zbiór `terminalSpike`), `settings.gradle.kts`, `libs.versions.toml`; pole `moduły:` w roadmapie to `terminal:impl, app`.

**Obserwacje spike'a (bez blokowania):**

- Option jako Meta (docs/06, domyślnie włączone) koliduje z polską klawiaturą (⌥A = „ą”). Rekomendacja: K5 rozstrzyga; prawdopodobnie domyślnie tylko lewy Option jako Meta (decyzja w AM-504).
- Z-order: `SwingPanel` zwykle rysuje się nad Compose, więc paleta ⌘K może być zasłonięta. F6 sprawdza `compose.interop.blending`; jeśli nie pomoże, paleta jako osobne okno (`Popup` w warstwie okna).
- ⌘K przy fokusie w terminalu prawdopodobnie nie dociera do `Window(onKeyEvent)`. F3 rozstrzyga między `KeyEventDispatcher` w `app` a przekazywaniem skrótów przez JediTerm; wynik idzie do ADR 0012 i AM-503/505.
- Notaryzacja (AM-902): pty4j wypakowuje natywne `libpty.dylib` i helper do katalogu tymczasowego. Do zbadania `pty4j.preferred.native.folder` z podpisanymi plikami w `.app`.
- Rozmiar: jary JediTerm, pty4j, JNA i jna-platform dodają szacunkowo kilka MB (zmierzyć w spike'u, wpisać do ADR). Kover ≥ 80% dla `terminal:impl`: kod widżetu bez ekranu może nie mieć pokrycia; jeśli brakuje, testy nie są pomijane na CI macOS (nie headless).
- `allWarningsAsErrors`: używać tylko nieprzestarzałych konstruktorów JediTerm (`JediTermWidget(settings)`).

**Szacunek linii:** `terminal:impl` ~180, okno spike'a ~170, Gradle ~40 → ~390 linii kodu (blisko limitu 400 z ENG-C10); testy ~150; dokumenty ~200.
