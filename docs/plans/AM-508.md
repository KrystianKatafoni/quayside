# AM-508 · Ustawienia terminala: powłoka, katalog startowy, font i rozmiar, scrollback, ligatury, Option jako Meta

Issue: #2 · Wymagania: FR-T7 (bez dzwonka, to AM-509), NFR-6, NFR-7 · ENG-I1–I8, ENG-C2, ENG-C8, ENG-T2 · docs/06 „Ustawienia terminala” · ADR 0012, ADR 0009, **ADR 0016 (przyjęta)** · Zależy: AM-503 (scalone)

## Zakres

Ustawienia z docs/06 trafiają do `terminal.json` (właściciel `terminal:impl`, docs/11 §8) i działają w **nowych** kartach i panelach (ADR 0016, decyzja 3). Rozmiar przekracza 300 linii, więc są **dwie części**, każda w osobnym PR do issue #2:

- **Część A (`feat/AM-508-terminal-settings`): zapis i zastosowanie.** Model i reguły w `terminal:api`, magazyn i zastosowanie w JediTerm/pty4j w `terminal:impl`, katalog startowy i etykieta karty w `terminal:ui`/`app`. Ustawienia zmienia na razie tylko plik.
- **Część B (`feat/AM-508-terminal-settings-ui`): dialog „Ustawienia terminala”** w `terminal:ui` i komenda palety/menu w `app`. Roadmapa dostaje `[x]` dopiero po części B (pytanie 1).

Co robi każde ustawienie:

| Ustawienie | Domyślnie | Zastosowanie |
| --- | --- | --- |
| `shell` | `LOGIN_DEFAULT` (`$SHELL`, dziś `/bin/zsh`) | `openShell` i podział: `[ścieżka, -l]`; `ZSH` `/bin/zsh`, `BASH` `/bin/bash`, `FISH` pierwszy istniejący z `/opt/homebrew/bin/fish`, `/usr/local/bin/fish`; brak → `StartFailed`. `openCommand` bez zmian (ADR 0016, decyzja 4) |
| `startDirectory` | `SESSION_WORKTREE` | ⌘T / „Nowa powłoka”: `cwd` sesji zaznaczonej w MC, jeśli należy do tego projektu, inaczej katalog projektu; `PROJECT`; `HOME`. Podział panelu: katalog karty aktywnej (bez zmian) |
| `fontFamily` | `null` (font JediTerm) | `getTerminalFont()`; font spoza systemu → domyślny + WARN `fontMissing` |
| `fontSize` | 13 | `getTerminalFontSize()`, zakres 8–32 |
| `scrollbackLines` | 100 000 | `getBufferMaxLinesCount()`, zakres 1 000–100 000 |
| `ligatures` | `true` | `TextAttribute.LIGATURES` w foncie terminala |
| `optionAsMeta` | `false` (decyzja człowieka 2026-10-31, ADR 0016) | `altSendsEscape()`; tylko oba Option naraz (JediTerm nie rozróżnia lewego i prawego), pytanie 2 |

**Nie robimy:** dzwonka (AM-509), zmiany otwartych kart na żywo, bloków komend, linków do IDEA, kopiowania przy zaznaczeniu (docs/06, poza FR-T7), fontu z typografii `appearance` (moduł nie istnieje), listy fontów w dialogu, zmian w `core:storage`.

## Zmiany API

`TerminalApi`, `TerminalSession`, `TerminalSearch`: bez zmian. Część B dodaje publiczne API `terminal:ui` (używa go `app`): `TerminalSettingsController` (`state`, `open`, `edit`, `save`, `cancel`), `SettingsDraft`, `SettingsDialogState` i composable `TerminalSettingsDialog(controller)`.
```kotlin
// terminal:api
/** Shell of new shell tabs (FR-T7). [LOGIN_DEFAULT] is the user's login shell (`$SHELL`). */
public enum class ShellProfile { LOGIN_DEFAULT, ZSH, BASH, FISH }

/** Where a new shell tab starts (FR-T7, docs/06). */
public enum class StartDirectory { SESSION_WORKTREE, PROJECT, HOME }

/** Terminal settings (docs/06 defaults). Apply to tabs opened later, never to open ones (ADR 0016). Immutable. */
public data class TerminalSettings(
    val shell: ShellProfile = ShellProfile.LOGIN_DEFAULT,
    val startDirectory: StartDirectory = StartDirectory.SESSION_WORKTREE,
    /** null: the terminal's default monospace font. */ val fontFamily: String? = null,
    val fontSize: Int = 13,
    val scrollbackLines: Int = 100_000,
    val ligatures: Boolean = true,
    /** Option sends Escape (Meta); also blocks Option characters such as `ą`. */ val optionAsMeta: Boolean = false,
)

public enum class TerminalSettingsField { FONT_FAMILY, FONT_SIZE, SCROLLBACK_LINES }

/** Why [TerminalSettingsRepo.update] saved nothing; the current settings stay. */
public sealed interface TerminalSettingsError {
    public data class Invalid(val field: TerminalSettingsField) : TerminalSettingsError
    /** `terminal.json` could not be written, or was written by a newer app (never overwritten). */
    public data object StorageFailed : TerminalSettingsError
}

/** What happened to `terminal.json` at start; null in [TerminalSettingsRepo.issue] when nothing. */
public enum class TerminalSettingsIssue { RECOVERED_FROM_BROKEN_FILE, READ_FAILED, NEWER_SCHEMA }

/** Stored terminal settings. Safe on any dispatcher; [update] suspends on file IO and never throws. */
public interface TerminalSettingsRepo {
    public val settings: StateFlow<TerminalSettings>
    public val issue: StateFlow<TerminalSettingsIssue?>
    /** Validates `change(current)` with [TerminalSettingsRules], saves it and publishes the saved value. */
    public suspend fun update(change: (TerminalSettings) -> TerminalSettings):
        Outcome<TerminalSettings, TerminalSettingsError>
}

/** Pure rules shared by impl, fakes and the dialog. */
public object TerminalSettingsRules {
    public val FONT_SIZES: IntRange = 8..32
    public val SCROLLBACK_LINES: IntRange = 1_000..100_000
    public const val MAX_FONT_FAMILY_LENGTH: Int = 80
    /** Trims [TerminalSettings.fontFamily] (blank → null), then checks the ranges; first bad field wins. */
    public fun validate(settings: TerminalSettings): Outcome<TerminalSettings, TerminalSettingsError.Invalid>
    /** [sessionDir] counts only for [StartDirectory.SESSION_WORKTREE]; null falls back to [projectDir]. */
    public fun startDirOf(choice: StartDirectory, projectDir: Path, sessionDir: Path?, home: Path): Path
    /** Tab label: the file name of [loginShell] for LOGIN_DEFAULT, else `zsh`, `bash`, `fish`. */
    public fun shellLabelOf(profile: ShellProfile, loginShell: Path): String
}

// terminal:impl (public factories only)
/** Opens `terminal.json` in [storage]; suspends until loaded, final [TerminalSettingsRepo.issue] on return. */
public suspend fun terminalSettingsModule(storage: JsonStorage, logger: Logger): TerminalSettingsRepo
/** [shell]: login shell for commands and LOGIN_DEFAULT; [settings] read at every open. */
public fun terminalModule(dispatchers: AppDispatchers, scope: CoroutineScope, logger: Logger,
                          shell: Path, settings: StateFlow<TerminalSettings>): TerminalApi   // ENG-C2 ≤ 5
// internal (testy): przeciążenie z `launch: TerminalLaunch` niesie też `baseEnvironment`
internal class TerminalLaunch(val shell: Path, val settings: StateFlow<TerminalSettings>,
                              val baseEnvironment: Map<String, String> = System.getenv())
internal fun terminalModule(dispatchers: AppDispatchers, scope: CoroutineScope, logger: Logger,
                            launch: TerminalLaunch): TerminalApi

// terminal:ui
/** Label and dir of new shell tabs (AM-508); read at every [TerminalController.openShell]. Main thread. */
public interface ShellStart { public val label: String; public fun dirOf(project: TerminalProject): Path }
public class TerminalController(terminals: TerminalApi, scope: CoroutineScope, logger: Logger, shellStart: ShellStart)
```

`TerminalLaunch` i przeciążenie z `launch` są `internal`, bo test architektury `impl exposes only its module factory` (ENG-C2) dopuszcza w `impl` publicznie tylko fabrykę modułu; publiczna fabryka przyjmuje więc `shell` i `settings` (5 parametrów).

Wewnętrzne: `ShellProfiles.resolve(profile, loginShell, exists: (Path) -> Boolean): Path?` (czysta); `TerminalWidgetSettings(settings: TerminalSettings, fontAvailable: (String) -> Boolean)` — migawka przy budowie widżetu; `JsonTerminalSettingsRepo` z `Mutex` (publikacja w kolejności zapisów), dla `NEWER_SCHEMA`/`READ_FAILED` domyślne i `update` → `StorageFailed`. `openShell` zapisuje w karcie `project.copy(dir = shellStart.dirOf(project))`, więc podział startuje w tym samym katalogu. `app`: `SettingsShellStart(settings, loginShell, home, selectedSessionDir: (ProjectId) -> Path?)`; `selectedSessionDir` czyta na świeżo `missionControl.attachTarget()` i `cwd` z `sessions.monitor.snapshot.value`. Logi: INFO `terminal settings saved` bez wartości, WARN z kategorią (`fontMissing`, `shellMissing`, `storageFailed`).

## Ryzyka i pytania

**Pytania blokujące: brak** dla części A. Pytania nieblokujące (zostaje decyzja domyślna):

1. **Podział na dwa PR**: zatwierdzone przez człowieka (A i B jako dwa PR do #2, `[x]` po B).
2. **Option jako Meta: domyślnie wyłączone** (decyzja człowieka). Polskie znaki z ⌥ działają; ⌥B/⌥F jako Meta włącza ustawienie. JediTerm nie pozwala na „tylko lewy Option”.
3. **ADR 0016**: przyjęty przez człowieka.
4. Podział karty `attach` startuje w katalogu projektu (jak dziś), nie w worktree tej sesji. Poprawka wymaga `cwd` w `AttachTarget` (`mission-control:ui`); poza zakresem.

**Rozmiar** (netto `src/main`, z zapasem 30%): A — `api` ok. 50, `impl` ok. 130, `ui` ok. 10, `app` ok. 30 → **ok. 290**; testy ok. 550. B — dialog i kontroler ok. 210, `app` ok. 25, teksty ok. 20 → **ok. 330**. Obie części mieszczą się w ENG-C10 (≤ 400).

**Rozmiar B, rzeczywisty:** `git diff main` dla `src/main/*.kt`, bez importów, pustych linii i KDoc/komentarzy: +419 / −13 = **netto ok. 406 linii** (`TerminalSettingsDialog.kt` 139, `TerminalSettingsControls.kt` 112, `TerminalSettingsController.kt` 90, `app` 42 dodane, `TerminalStrings.kt` 23, `TerminalTags.kt` 13); surowy `--numstat`: +612 / −13. Plan mówił ok. 330. **Odstępstwo od ENG-C10 (≤ 400) do akceptacji przez człowieka**: część B to jeden spójny dialog (kontrolki, kontroler, okablowanie w `app`), a podział na trzeci PR rozdzieliłby kontroler od ekranu, który go testuje.

**Uwaga (poza zakresem):** przy `READ_FAILED` / `NEWER_SCHEMA` przycisk „Zapisz” jest aktywny, ale repo niczego nie zapisuje (`writable = false`) i dialog pokazuje tylko ogólny błąd zapisu; wyłączenie przycisku w tych stanach to osobne zadanie.

**Ryzyka:**

- Ligatury: JediTerm 3.76 może rysować znak po znaku; wtedy `LIGATURES` nic nie da (ADR 0012 H3 widział ligatury, sprawdzić ręcznie). Test sprawdza tylko atrybut fontu.
- Scrollback 100 000 (dziś domyślne JediTerm, prawdopodobnie 5 000 — sprawdzić `getBufferMaxLinesCount`) zwiększa RAM na kartę i czas migawki ⌘F (`JediTermSearch` na wątku Swing). Pomiar ręczny; jeśli NFR-7 pada, obniżyć domyślne w ADR 0016.
- `terminalModule` zmienia sygnaturę: poprawić `TerminalTestKit` i `Main.kt` w tym samym commicie. `projects`-podobny `runBlocking` w `main` dla `terminalSettingsModule` (ENG-C3 dopuszcza w `main`).
- Lekcja o KDoc: `TerminalWidgetSettings` („13 pt font”), `TerminalController` („[shellLabel] names shell tabs”), `TerminalDeps` („the shell tab label”), docs/11 §4 („settings dochodzą w AM-508”) — poprawić teksty.
- Lekcja o `stateIn`: `SettingsShellStart` czyta `settings.value` i zaznaczenie MC w chwili otwarcia, nie z kombinacji po `stateIn`.
- `fontFamily` jest daną użytkownika tylko pośrednio, ale logów nie zawiera (stałe kategorie, ENG-C8).
