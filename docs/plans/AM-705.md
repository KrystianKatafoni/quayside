# AM-705 · Cisza nocna, tryb Skupienia, wyjątki per projekt

Issue: #13 · Wymagania: FR-N6, FR-N7 · docs/07 (przełączniki globalne, „Wyjątki per projekt”), docs/11 §4 i §8, docs/12 §4 scenariusz 6, ENG-I1–I8, ENG-C2, ENG-C6, ENG-C8, ENG-C10 · Zależy: AM-704 (scalone) · Wzór: AM-703, AM-704

## Zakres

Decyzje człowieka (2026-11-03): AM-705 to **tylko logika** (`api`, `impl`, spięcie w `app`) w dwóch PR; UI przechodzi do nowego zadania AM-706 (sekcja „Follow-up AM-706”); Skupienie macOS w tym zadaniu to tylko port; cisza nocna jest **domyślnie wyłączona**.

**FR-N6.** „Nie przeszkadzać” w godzinach od–do: domyślnie `enabled = false`, godziny domyślne 22:00–07:00 (docs/07) gotowe do włączenia w UI AM-706. Przełącznik „Respektuj Skupienie macOS” (`respectFocus`, domyślnie włączony) działa niezależnie od godzin. W ciszy (włączone godziny obejmują chwilę zdarzenia albo aktywne Skupienie przy `respectFocus`) odpadają kanały **VOICE i SOUND**; POPUP i DOCK_BADGE zostają (docs/12 §4 scenariusz 6). Bez wyjątków dla rodzajów (błąd też nie mówi). Godzina lokalna = `clock.now()` w strefie z `zone()`, czytanej przy każdym zdarzeniu.

**FR-N7.** Wyjątek projektu = profil + opcjonalny głos. `DEFAULT`: bez zmian. `ERRORS_ONLY`: tylko rodzaj `FAILED` (jego kanały z macierzy), inne rodzaje nic. `MUTED`: tylko `DOCK_BADGE` (docs/07 „tylko badge w Docku”; badge działa od AM-903, do tego czasu nic). Głos projektu zastępuje globalny głos komunikatu tej sesji; grupa z sesji kilku projektów mówi głosem globalnym. Sesja bez projektu, projekt bez wpisu i dzwonek terminala = `DEFAULT`. Wyciszenie sesji na 15 min działa jak dotąd.

Kolejność filtrów w `decide`: macierz → przełączniki globalne → profil projektu → cisza (VOICE, SOUND) → `voiceAllowed` (okno w tle, mikrofon).

**Skupienie macOS:** tylko port `FocusMonitor` z `NoFocus` (zawsze nieaktywne), jak `NoMicrophone`. Adapter jest osobnym zadaniem (sekcja „Follow-up: adapter Skupienia”).

**Nie robimy:** UI (AM-706), adaptera Skupienia, dni tygodnia, kilku przedziałów, wyjątków ciszy dla rodzajów, „cisza też dla popupów”, kanałów per projekt poza profilem, „języka głosu wg projektu” z docs/07, sprzątania wpisów usuniętych projektów.

**Dwa PR:**

- **A** `feat/AM-705-quiet-hours` (`Refs: #13`): model ciszy, reguła, `FocusMonitor`, serializer, `zone` w fabryce. **Ok. 180 linii.**
- **B** `feat/AM-705-project-profiles` (`Closes #13`, roadmapa `[x]`): model wyjątków, profil w `decide`, głos projektu w `VoiceNotifier`, serializer, docs/03. **Ok. 180 linii.**

## Zmiany API (`notifications:api`)

```kotlin
/**
 * Do-not-disturb hours and macOS Focus (FR-N6, docs/07). While quiet, voice and sound are dropped; popups and the
 * Dock badge stay. Immutable; times are whole minutes.
 * @property enabled the hours apply; off by default. [respectFocus] works on its own.
 * @property from start of the quiet time, inclusive. @property to end, exclusive; [to] before [from] crosses
 *   midnight; [from] equal to [to] is never quiet.
 * @property respectFocus quiet while a macOS Focus is on (no effect until the Focus adapter exists).
 */
public data class QuietHours(
    val enabled: Boolean = false, val from: LocalTime = DEFAULT_FROM, val to: LocalTime = DEFAULT_TO,
    val respectFocus: Boolean = true,
) {
    init { /* require second == 0 and nano == 0 for both */ }
    public companion object { public val DEFAULT_FROM: LocalTime /* 22:00 */; public val DEFAULT_TO: LocalTime /* 07:00 */ }
}

/** How a project's sessions notify (FR-N7). */
public enum class ProjectProfile { DEFAULT, ERRORS_ONLY, MUTED }   // KDoc per constant as in Zakres

/** The exception of one project; [voice] null = the global voice. Default = no exception. */
public data class ProjectNotifications(val profile: ProjectProfile = ProjectProfile.DEFAULT, val voice: VoiceId? = null)

// NotificationSettings: new last parameters (A, B) and a lookup (B)
val quietHours: QuietHours = QuietHours(),
val projects: Map<ProjectId, ProjectNotifications> = emptyMap(),   // only deviations are stored
/** The exception of [project]; the default for null or a project without an entry. */
public fun projectFor(project: ProjectId?): ProjectNotifications
```

`java.time.LocalTime` to typ JDK (niemutowalny, jak `Instant` w `Clock`), nie biblioteki (ENG-I8).

**`impl` (wszystko `internal`):**

- `DeliveryContext(appActive, microphoneActive, localTime: LocalTime, focusActive: Boolean)` (4 pola, ENG-C2). `fun QuietHours.covers(time: LocalTime): Boolean` (półotwarty przedział, przez północ). `fun quietNow(quiet: QuietHours, context: DeliveryContext): Boolean` = `(enabled && covers(localTime)) || (respectFocus && focusActive)`. `VoiceNotifier.allowedNow()` dodaje `!quietNow` (grupa po 20 s w ciszy przepada).
- `interface FocusMonitor { val active: StateFlow<Boolean> }`, `object NoFocus` (nazwa jak `MicrophoneMonitor`).
- B: `fun profileAllows(profile: ProjectProfile, kind: NotificationKind, channel: NotificationChannel): Boolean` w `ProjectRules.kt` (czysta; odciąża `NotificationPolicy.kt` przed TooManyFunctions). `VoiceMessage` i `VoiceAction.Speak` dostają `project: ProjectId?` (grupa: wspólny projekt albo null); kolejka niesie `Speak`, a głos wybiera `settings.projectFor(project).voice ?: speech.voice` w chwili mówienia.
- `notifications.json` (bez zmiany `schemaVersion`, jak AM-703): `"quietHours": {"enabled", "from": "22:00", "to": "07:00", "respectFocus"}`; `"projects": {"<uuid>": {"profile": "errorsOnly", "voice": "Anna"}}`. Brak klucza = domyślne; czas spoza `HH:MM` 00:00–23:59 i nieznany profil = domyślne; zły typ → `.broken`; wpis domyślny nie jest zapisywany. `ProjectId` to UUID (bez ścieżek w pliku). Logi tylko ze stałą kategorią (ENG-C8).

**Fabryka (ENG-C2).** `notificationCenterModule(settings, scope, clock, zone: () -> ZoneId, events, …)` ma 10 parametrów pod istniejącym `@Suppress("LongParameterList")`; `zone` bez wartości domyślnej (testy hermetyczne, ENG-T6), więc zmieniają się 2 wywołania w testach i `app`. Obiekt parametrów nie jest tani: `impl` może wystawiać tylko fabryki (Konsist), więc publiczny typ parametrów musiałby trafić do `notifications:api`, a ten nie widzi `core:process` (`ProcessRunner`, reguła 3 docs/11) ani nie powinien nieść typów okablowania. Zostaje precedens AM-703 (pyt. 6) i KDoc fabryki z uzasadnieniem.

## Ryzyka i pytania

**Pytania blokujące: brak** (decyzje 2026-11-03 w sekcji „Zakres”). Pytania nieblokujące (plan przyjmuje rekomendację):

1. Wyjątki w `notifications.json` (docs/11 §8: jeden właściciel pliku), nie w `projects.json` + `Project.notifyProfile` z docs/03 — tamto zmienia `projects:api` innego feature. B poprawia docs/03.
2. W ciszy milkną VOICE i SOUND, także dla `FAILED` i `PERMISSION`; bez dni tygodnia; `od == do` = nigdy.
3. `ERRORS_ONLY` = tylko `FAILED` (nie `PERMISSION`); docs/07 „Tylko błędy, bez głosu” z uwagą „głos po niemiecku” jest sprzeczne — profil i głos są niezależne.
4. `respectFocus` domyślnie włączony: do adaptera nie ma skutku (`NoFocus`).
5. Bez podbicia `schemaVersion`: starsza wersja aplikacji zapisze plik bez `quietHours` i `projects` (to samo ryzyko co `speech` w AM-703).

**Ryzyka:**

- Między AM-705 a AM-706 cisza i wyjątki działają tylko po ręcznej edycji `notifications.json`.
- Wpisy usuniętych projektów zostają w pliku (UUID nie wraca); nieszkodliwe.
- Zmiana profilu na `MUTED` w trakcie 20 s chłodzenia nie zatrzymuje zebranej grupy (sprawdzane są głos, `voiceAllowed` i cisza).
- `ZoneId.systemDefault()` JVM nie widzi zmiany strefy systemu bez restartu — sprawdzić ręcznie.
- Zmiana `DeliveryContext` łamie konstrukcje w `VoiceNotifierTest`, `DefaultNotificationCenterTest`, `NotificationPolicyTest` — w tym samym PR A; w testach `localTime = LocalTime.NOON`.
- Detekt: gdy wymusi pliki spoza listy (TooManyFunctions, CyclomaticComplexMethod), dopisać je do „Moduły” w tym samym PR (lekcja).
- Rozmiar (netto `src/main`, zapas 30%): A ok. 140 → 180; B ok. 140 → 180. Razem ok. 360 (> 300), dlatego osobno.
