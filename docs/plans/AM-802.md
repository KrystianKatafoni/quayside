# AM-802 · core:design-system: komponenty i AmTheme + fonty 8 podstawowych typografii w zasobach

Issue: #15 · Wymagania: FR-A1, NFR-6 · docs/08 („Typografie”, l. 82–84), docs/11 §2–§3, docs/12 §1, ENG-I1–I8, ENG-C2, ENG-C10, ADR 0021 (proponowana) · Zależy: AM-801 (scalone)

## Zakres

Decyzje człowieka (2026-11-03): ADR 0021 zaakceptowany w proponowanej treści (status „proponowana” zmienia się na „przyjęta” przy scaleniu PR); fonty pobiera implementer w commicie 2; follow‑up AM-806 dopisuje commit 4; **jeden PR** ok. 680 linii `src/main` z KDoc i Gradle (bez plików fontów); świadomy wyjątek od ENG-C10 za zgodą człowieka, opis PR to wymienia.

**Robimy:** (1) nowy moduł `core:design-system` (Compose, explicit API); (2) `AmTheme` z trzema `CompositionLocal`: `ColorTokens`, `AmShape` (z `ShapeTokens`), `AmTypography` (z `TypographySpec`); (3) minimum komponentów dla ekranu Wygląd (AM-803, zrzut `22-ustawienia-wygladu.png`): `AmText`, `AmButton` (główny / zwykły), `AmListRow` (wiersz wyboru motywu i typografii), `AmPanel` (karta, sekcja „Szczegóły”, ciało popupu), `AmModeBar` + `AmModeBadge` (pasek trybu z podglądu), `Modifier.amFocusFrame()`; (4) 14 rodzin fontów 8 podstawowych typografii w `resources/fonts` z `OFL.txt` i `SOURCES.md` (ADR 0021); (5) testy mapowania, UI, kontrastu, fokusu i znaków.

**Nie robimy:** migracji istniejących ekranów i usunięcia 8 lokalnych palet (`Colors` MC, `NewAgentColors`, `SidebarColors`, `TerminalColors` ui, `PopupColors`, `SettingsColors`, `PaletteColors`, `HookColors`) — AM-806; `AmPopup` jako okno `Popup` (pytanie 2); rysowania `shadow` i `Backdrop.TRANSLUCENT` poza kolorem (motywy z kształtem, AM-805); skali `uiScale`/`density` (AM-803/804); fontu terminala w JediTerm (AWT); fontów 14 typografii dodatkowych (AM-805); wpięcia w `app`, `appearance:*`, CHANGELOG (nic widocznego).

**Kolejność commitów** (każdy z zielonym `./gradlew check`): (1) moduł + Gradle + Konsist + `AmTheme`, mapowania i ich testy; (2) fonty, `OFL.txt`, `SOURCES.md`, `AmFonts` i test znaków; (3) komponenty i testy UI/kontrastu; (4) dokumentacja (docs/08 l. 82: fonty 8 podstawowych są w zasobach; docs/11 §4 blok `core:design-system`; ADR 0021 zostaje „proponowana”, przyjęcie przy scaleniu; `docs/ROADMAP.md`: AM-802 `[x]`, nowa linia po AM-805 `- [ ] AM-806 · Ekrany na AmTheme: usunięcie 8 lokalnych palet i kopii kontrolek · moduły: mission-control:ui, projects:ui, terminal:ui, notifications:ui, command-palette:ui, app · zależy: AM-802 · wymagania: FR-A1, NFR-6 · issue: —`, w AM-803 „zależy: AM-802, AM-405, AM-806”, w „Uwagach do M8” zdanie: „AM-803 zależy od AM-806, bo podgląd na żywo pokazuje prawdziwy ekran Mission Control, który musi czytać kolory z `AmTheme`”).

## Zmiany API

```kotlin
// core:design-system — wszystko na wątku kompozycji (UI); typy niemutowalne
/** Compose colour of a token; alpha kept (translucent panel is drawn over bg by the caller's layout). */
public fun Rgba.toColor(): Color
/** Shape tokens as Compose values. [corner] = RoundedCornerShape(radius.dp); shadow and backdrop as in ShapeTokens (drawn from AM-805). */
@Immutable public data class AmShape(val corner: Shape, val borderWidth: Dp, val shadow: ShadowSpec?, val backdrop: Backdrop)
public fun ShapeTokens.toAmShape(): AmShape
/** Text roles of the design system; sizes in sp: TITLE 20, HEADING 15, BODY 13, CAPTION 11, CODE 13 (mono). */
public enum class TextRole { TITLE, HEADING, BODY, CAPTION, CODE }
/** UI and mono families of a typography and the text style of every role (TITLE/HEADING SemiBold, rest Normal). */
@Immutable public class AmTypography(public val ui: FontFamily, public val mono: FontFamily) {
    public fun style(role: TextRole): TextStyle      // CODE uses [mono], the rest [ui]; no colour
}
/** Bundled OFL fonts (ADR 0021), looked up by family name as in TypographySpec. Never throws. */
public object AmFonts {
    public val families: Set<String>                 // the 14 bundled family names, docs/08 spelling
    public fun family(name: String): FontFamily?     // null = not bundled (e.g. system fonts of AM-805)
}
/** Unknown names fall back to FontFamily.Default (ui) and FontFamily.Monospace (terminal font). */
public fun TypographySpec.toAmTypography(): AmTypography

/** Provides theme values to [content]; nested AmTheme overrides the outer one. 4 params (ENG-C2). */
@Composable public fun AmTheme(colors: ColorTokens, shape: ShapeTokens, typography: TypographySpec, content: @Composable () -> Unit)
/** Current theme; reading outside AmTheme fails with "AmTheme is missing" (programmer error, not a runtime state). */
public object AmTheme {
    public val colors: ColorTokens @Composable @ReadOnlyComposable get
    public val shape: AmShape @Composable @ReadOnlyComposable get
    public val typography: AmTypography @Composable @ReadOnlyComposable get
}

/** One line of text in [role]; [color] null = content.text. */
@Composable public fun AmText(text: String, modifier: Modifier = Modifier, role: TextRole = TextRole.BODY, color: Color? = null)
public enum class ButtonKind { PRIMARY, SECONDARY }   // PRIMARY: accentInk on accent; SECONDARY: text on raised, border2 frame
/** Focusable button (Role.Button); Space/Enter click it while focused. Disabled: dim label, ignores clicks, announced disabled. */
@Composable public fun AmButton(label: String, onClick: () -> Unit, modifier: Modifier = Modifier, kind: ButtonKind = ButtonKind.SECONDARY, enabled: Boolean = true)
/** Selectable row: sel background, ✓ at the end and `selected` semantics when [selected] (not colour only, NFR-6). Focusable. */
@Composable public fun AmListRow(selected: Boolean, onClick: () -> Unit, modifier: Modifier = Modifier, content: @Composable RowScope.() -> Unit)
/** Surface with corner radius, border width and colour (border) of the theme; [raised] = raised instead of panel. */
@Composable public fun AmPanel(modifier: Modifier = Modifier, raised: Boolean = false, content: @Composable BoxScope.() -> Unit)
/** Bottom status bar: panel background, border on top, CAPTION text in muted by default. */
@Composable public fun AmModeBar(modifier: Modifier = Modifier, content: @Composable RowScope.() -> Unit)
/** Mode label like `NORMAL`: accentInk on accent. */
@Composable public fun AmModeBadge(text: String, modifier: Modifier = Modifier)
/** 2 dp frame in content.text while focused, outside the element with a 2 dp gap of container background; 4 dp always reserved (≥ 3:1 on bg, panel, raised, sel by the AM-801 audit). Put before the focusable modifier. */
@Composable public fun Modifier.amFocusFrame(): Modifier
```

**`internal`:** `ComponentColors` — czyste funkcje `buttonColors(kind, enabled, tokens): Pair<Rgba, Rgba>` (tło, napis), `badgeColors(tokens)`, `rowColors(selected, tokens)`, `modeBarColors(tokens)`, `panelColors(raised, tokens)` (wypełnienie, ramka), `buttonBorder(tokens)`, `modeBarBorder(tokens)`, `focusColor(tokens)`; komponenty biorą kolory tylko stąd, więc test kontrastu pokrywa każdą parę. `AmPanel` i `AmListRow` resetują `LocalTextColor` do `content.text`, żeby kolor z `AmModeBar` (muted) nie trafił na `raised`/`sel`, czego audyt nie sprawdza. `AmFonts.resourcePaths` (internal) = wszystkie ścieżki zasobów z tabeli, dla testu classpath. `LocalAmColors/Shape/Typography` = `staticCompositionLocalOf { error("AmTheme is missing") }`. `AmFonts` tabela: nazwa → lista (`fonts/<katalog>/<plik>`, waga); plik zmienny = dwa `Font(resource, weight)` z tą samą ścieżką. Przed użyciem `Font(resource = …)` implementer sprawdza w źródłach Compose MP 1.12 (`*-desktop` na repo1.maven.org), że przeciążenie nie jest `@Deprecated` (lekcja `allWarningsAsErrors`).

## Ryzyka i pytania

**Pytania blokujące: brak** (decyzje 2026-11-03 w sekcji „Zakres”: ADR 0021 zaakceptowany, fonty pobiera implementer przez `curl`, AM-806 i zależność AM-803 dopisuje commit 4, jeden PR ponad ENG-C10).

**Pytania nieblokujące (plan przyjmuje rekomendację):**

1. `AmPopup` (okno `Popup` z fokusem) odkładamy do pierwszego użytkownika; `AmPanel` jest jego ciałem. Lekcje o fokusie `Popup` dotyczą tego zadania.
2. Ramka fokusu w kolorze `text` (kontrast gwarantowany przez audyt AM-801), a nie `accent` (audyt nie sprawdza `accent` na `bg`/`panel`). Ramka graniczy z tłem kontenera, nie z przyciskiem: `amFocusFrame` zawsze rezerwuje 4 dp (2 dp ramki + 2 dp odstępu), a `border` rysuje tylko przy fokusie, więc układ się nie przesuwa. Bez odstępu 2 dp `text` zastępowałoby krawędź `accent` przycisku głównego (kontrast text/accent 2,19:1 plex, 2,24:1 paper < 3:1). Koszt: każdy fokusowalny element ma 4 dp marginesu wokół siebie.
3. `AmTheme.colors` to `ColorTokens` + `Rgba.toColor()` zamiast drugiego zestawu 19 pól `Color` (jedno źródło prawdy; koszt: `.toColor()` w wywołaniach).
4. Test „każda typografia katalogu ma fonty” (`BuiltInTypographies` ↔ `AmFonts.families`) wymaga obu modułów — dopisuje go AM-803 w `appearance:ui`; tu lista 14 nazw w teście.

**Ryzyka:**

- PR ok. 680 linii (zgoda człowieka): commity w kolejności z „Zakres”.
- Próg pokrycia `core:*` to 90 % (Kover): każda gałąź komponentu potrzebuje testu UI; `AmFonts` pokrywa test parametryczny.
- Compose Desktop może nie stosować osi `wght` pliku zmiennego: test `variable font semi bold renders wider than regular` to wykryje; wtedy implementer zatrzymuje się i zgłasza (fallback: statyczne pliki z wydań autorów, zmiana ADR 0021).
- `AmListRow` i `AmButton` są fokusowalne i biorą Space/Enter (lekcja): na ekranach ze skrótami bez ⌘ (Mission Control) migracja musi to uwzględnić.
- Composable blisko LongMethod (30) i ENG-C2 (≤ 5 parametrów; `AmButton` ma 5) — mierzyć ręcznie; nie dokładać parametrów, nowe warianty przez `ButtonKind`.
- `java.awt.Font` w testach: na CI bez ekranu ustawić `java.awt.headless=true` w `tasks.test` tego modułu.
- Rozmiar `.dmg` rośnie o kilka MB; licencje OFL do pakietu w AM-901.
