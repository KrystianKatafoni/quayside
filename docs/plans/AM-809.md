## Zmiany API

Brak zmian w `api` jakiegokolwiek feature. Publiczne w `core:design-system` i modułach `ui` (używa ich tylko `app`):

```kotlin
// core:design-system
/** PRIMARY accentInk on accent (one per view); SECONDARY text on raised, border2; DANGER err outline, no fill. */
public enum class ButtonKind { PRIMARY, SECONDARY, DANGER }

/** Options of [AmButton]. [icon] 16 dp before the label, in the label colour. [shortcut] (e.g. "⌘N", "r") after the
 *  label in CODE, label colour, no frame; read with the label as one node. [focusable] false: never takes focus,
 *  so Space and Enter reach window shortcuts; no focus frame, no reserved 4 dp (as [IconButtonOptions]). */
public data class ButtonOptions(val kind: ButtonKind = ButtonKind.SECONDARY, val enabled: Boolean = true,
    val focusable: Boolean = true, val icon: IconKind? = null, val shortcut: String? = null)

/** Button (Role.Button) with [label]; content centred when [modifier] widens it. Disabled: dim, announced disabled. */
@Composable public fun AmButton(label: String, onClick: () -> Unit, modifier: Modifier = Modifier,
    options: ButtonOptions = ButtonOptions())

/** Mark colour of this tone for icons (toneColor of AM-808): 3:1 audited on bg, panel, raised, sel (plex). */
@Composable public fun StatusTone.markColor(): Color
```

`internal`: `data class ButtonColors(val background: Rgba, val border: Rgba?, val label: Rgba)`, `buttonColors(kind, enabled, tokens)`; `DANGER`: obrys `tinted(err)` 35 % (jak `AmIconButton DANGER`), etykieta `err`, gdy ≥ 4,5:1 na `panel`, inaczej `text`. Wywołania `kind =`/`enabled =` (2 w `src/main`) przechodzą na `options`; wywołania z `label, onClick, modifier` (notifications:ui, terminal:ui) bez zmian.

## Ryzyka i pytania

**Pytania blokujące: brak** (żadne `api` feature się nie zmienia; `ui` → `core:design-system` i `app` → `ui` zgodne z regułami 1 i 5 docs/11; bez ADR).

**Pytania nieblokujące (plan przyjmuje rekomendację; człowiek potwierdza przed etapem 6):**

1. **Kiedy okno przechodzi w układ B.** Mockup B jest „po kliknięciu Attach”, a docs/06 mówi: terminal pod listą **i** tryb pełnoekranowy z przycisku, bez skrótu. Rekomendacja: zgodnie z docs/06 (Attach nie zmienia trybu, wejście przyciskiem pełnego ekranu i komendą palety, bez nowego skrótu); brak regresji AM-503/511. Alternatywa: Attach włącza tryb terminala — zmienia obecne scenariusze okna i wymaga decyzji, jak wrócić klawiaturą (Esc zabiera Claude Code).
2. **„Odpowiedz” w wierszu jako `PRIMARY`** obok `PRIMARY` w panelu szczegółów (mockup A) łamie zasadę C „główna — jedna na widok”. Rekomendacja: jak A (wiersz i panel), bo to ta sama akcja tej samej sesji.
3. `keyCapOf` w `app` kopiuje `ShortcutLabel` (`internal` w `command-palette:ui`, poza modułami zadania). Rekomendacja: kopia z testem; uwspólnienie przy najbliższym zadaniu w `command-palette:ui`.
4. „Dodaj projekt z dysku…” na dole listy w A: usuwamy (C: „+” w nagłówku). Ton folderu bez „gotowe” (zielony w A) — `projects:ui` liczy tylko czekające i pracujące.

**Ryzyka:**

- Zmiana `AmButton` (`kind`/`enabled` → `options`) dotyka `app` i `mission-control:ui`; inne moduły używają tylko `label, onClick, modifier` — kompiluje się bez zmian.
- Przyciski na ekranach muszą być niefokusowalne; test „space po kliknięciu dochodzi do okna” dla każdego nowego miejsca (wiersz, panel, pasek sesji, pasek ikon).
- `SwingPanel` przy przełączeniu trybu: jeśli Compose utworzy widżet od nowa, terminal może zgubić fokus albo mignąć — `movableContentOf` zamiast `key`, ocena przy `:app:run` (brak testu automatycznego zachowania panelu).
- Pasek ikon renderuje dialogi projektów (pasek boczny nie istnieje w trybie terminala) — inaczej „+” bez okna błędu.
- Kontrast: `DANGER` i pigułki mają regułę awaryjną do `text`; audyt tylko `plex` (katalog w AM-803). `work` i `accent` w plex 1,47:1 — kafelek i pigułka mają też kształt ikony i tekst.
- Rozmiar ok. 1400 linii; composable bliskie LongMethod (nagłówek, wiersz, panel, pasek sesji) — wydzielać od razu; pliki wymuszone przez detekt dopisać do „Moduły”; zrzuty z `:app:run` w PR.
- Plan AM-803 trzeba po scaleniu zaktualizować (podgląd pokazuje nowy ekran). Przed pushem `npx --yes markdownlint-cli2@0.18.1`.

## Decyzje podjęte w trakcie

- Respawn na pasku sesji jest zawsze rysowany; wyłączony dla sesji aktywnej, a Zatrzymaj dla nieaktywnej.
- Menu „⋯" wiersza nie pokazuje skrótów (teksty `action.*` są bez skrótu, `keyCaps` idą tylko do przycisków).
- `AmIconButton` nie ma nakładki najechania ani naciśnięcia (`indication = null`); przyciski z tekstem ją zachowują.
- Popup Attach zaznacza projekt w pasku bocznym (`ProjectsIntent.Select`), potem sesję (`SelectSession`).
- Wyjście z trybu terminala po zamknięciu ostatniej karty: `WindowModeState.follow(menu, scope)`.
- `QuaysideApp` bierze `AppControllers` i `TerminalSlot` (ENG-C2).
