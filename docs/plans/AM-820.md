# AM-820 · Edytor własnych schematów, usuwanie i eksport schematu

Issue: #132 · Wymagania: FR-A6, NFR-6 · Etap: M8 · Zależy: AM-814 · ADR 0023 (uzupełnienie AM-820)

## Zakres

1. **Edytor** w oknie Wygląd: „Nowy schemat…” otwiera formularz (klucz `[a-z0-9-]+`, nazwa 1–40 znaków, promień 0–24, tryb jako lista rozwijana, osiem pól `#RRGGBB`), raport kontrastu NFR-6 pod polami (niepełny formularz, zajęty klucz, naruszone reguły, „w normie”), próbka w wyprowadzonych kolorach tylko dla poprawnego schematu i przycisk „Dodaj schemat” aktywny tylko po przejściu audytu. Dodanie zapisuje od razu, jak import (AM-814).
2. **Usuwanie**: „Usuń schemat” działa na własnym schemacie wybranym na liście; odmowa, gdy jest zapisanym motywem lub motywem dnia lub nocy. Szkic wybierający usunięty schemat wraca do zapisanego wyboru.
3. **Eksport pojedynczego schematu**: „Eksportuj schemat…” zapisuje plik motywu z jednym schematem i domyślnymi ustawieniami (nazwa `<klucz>.json`); plik wraca przez „Importuj schemat…”.

Nie robimy: edycji istniejącego schematu (zmiana koloru istniejącego klucza), zmiany formatu `theme.json`, kopiowania wartości kolorów z wbudowanych motywów do formularza (formularz startuje od kolorów `graphite`).

## Zmiany API (appearance:api)

```kotlin
public fun previewScheme(scheme: CustomScheme): Outcome<ThemeSpec, SchemeError>   // czysta, bez zapisu
public suspend fun removeScheme(id: SchemeId): Outcome<Unit, SchemeError>
// SchemeError: + NotFound(id), InUse(id)
```

Zmiana dotyczy tylko własnego modułu `appearance`; inne feature nie implementują `AppearanceApi`.

- `appearance:impl`: `JsonThemeStore` (`previewScheme`, `removeScheme` pod mutexem, zapis przez ten sam `save`), test integracyjny na `JsonStorage` (restart, klucz `customSchemes` znika, odmowa dla wybranego).

## Ryzyka

- `appearance:ui` i `appearance:impl` nie kompilują się w środowisku chmurowym (Compose i JediTerm); sprawdza je CI.
- Raport kontrastu liczy się przy każdej rekompozycji `Columns` (czyste wyprowadzenie ośmiu kolorów, tanie); katalog jest argumentem, więc zajęty klucz odświeża się po zmianie katalogu.
- `InUse` sprawdza zapisane ustawienia, nie szkic: schemat wybrany tylko w szkicu da się usunąć, a szkic wraca do zapisanego wyboru.
