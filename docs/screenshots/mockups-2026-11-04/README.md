# Mockupy z 2026-11-04

Zrzuty trzech plansz z artefaktu Design „Quayside – propozycje wyglądu” (motyw Plex Violet, fonty IBM Plex).
Są wzorcem wyglądu dla zadań AM-807 (kolory i font terminala), AM-808 (ikony i komponenty w
`core:design-system`) oraz AM-809 (przebudowa Mission Control i paska bocznego).

To propozycje projektowe, a nie zrzuty działającej aplikacji. Zrzuty powstały z plików HTML planszy
w headless Chrome, bez ramki edytora.

| Plik | Plansza | Rozmiar | Opis |
| --- | --- | --- | --- |
| `01-mission-control.png` | A · Mission Control | 1440×900 | Lista projektów z przyciskiem „+” w nagłówku, kafelki liczników, wiersze sesji ze statusem i akcjami, panel szczegółów z hierarchią przycisków. |
| `02-po-attach-terminal.png` | B · po kliknięciu Attach | 1440×900 | Terminal w kolorach motywu, pasek sesji nad terminalem, zwijany pasek ikon projektów, karty i podział terminala. |
| `03-ikony-przyciski-statusy.png` | C · ikony, przyciski i statusy | 1440×760 | Zestaw ikon liniowych, hierarchia przycisków, statusy jako ikona + kolor + tekst, zasady układu. |
